Anonymous statistics

Help count how many translAItarr2 instances are running

When on, the app sends once a day only a random id (generated on this instance) and the app version — nothing else. No file paths, API keys, library data, settings or IP addresses are sent or stored. It powers a public “active instances” counter, nothing more. Turn it off any time — a disabled instance sends nothing and doesn't even generate an id.

Import webhook — optional

Automation finds new files on its scan every few minutes. With this webhook, Sonarr/Radarr tell translAItarr2 right after an import, and a file that needs a subtitle is queued at once. The scan keeps working either way. The URL contains a secret token, so treat it like a password.

{% if cfg.webhook.enabled %}● On{% else %}Off{% endif %}

In Sonarr and Radarr: Settings → Connect → + → Webhook, tick On Import and On Upgrade, paste the URL, Method POST, then Test. If they run in the same Docker network, use the container name as the host, e.g. http://translaitarr2:9878/….
